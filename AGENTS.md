- Discord auto-linking (server join, voice join, post-match DMs; never public claim buttons) lives in `public/spotbot/auto-link.cjs`; profiles are global so a link in one server applies everywhere.
- Scouting stats split current EA FC season vs older seasons in `recruitment.statsFor`; season start comes from `FC_SEASON_START` env so a new game needs no code change.
- Players holding a position role are auto-added to the club roster (`roster.syncMemberPositions`, on role change and at startup); multi-club servers match by club name in a role, clubs opt out with `auto_roster: false`.
- Both the cloud sync (sync-ea-stats) and the bot relink pre-FC27 clubs by exact EA name and mark them ea_fc_version='fc27'; FC27 gave every club a new ID, so old IDs only return last season's matches.
- Bot database access goes through the `bot-proxy` function with a shared BOT_PROXY_SECRET; the admin key never leaves the backend.

- Recap action artwork is bundled in the bot assets and selected by the spotlight player’s position; it is labelled as AI art because EA stats and Discord avatars do not establish a player’s likeness.
- Recap cards display actual single-match ratings, not derived overall ratings, so match performance cannot be mistaken for EA player attributes.
- Event announcement mentions are enabled only in postEvent; board updates and reposts suppress mentions so availability changes never notify the whole server again.
- Pro photos are ingested only through the `pro-photo` function (bot secret, AI vision check, private storage with long-lived signed URLs); every accepted upload is retained in `pro_photo_assets`, while `pro_photos` stays as the latest-photo compatibility record.
- The bot requests Discord's Message Content intent (needed to see attachments for #pro-photos) and falls back to logging in without it if the portal toggle is off, so a missing toggle never takes the bot offline.
- Graphics Studio (`public/spotbot/graphics-studio.cjs`) gets text-free AI art from the `club-art` function and draws every word and stat itself in SVG, so names and numbers always come from saved data; club kit lives on the club config (`club.kit`).
- Graphics Studio acknowledges data-loading interactions before cloud reads and opens edit forms from user-bound prepared drafts, so Discord's three-second response deadline cannot silently discard selections.
- Graphics Studio selects non-repeating pose/layout pairs through `graphics-variants.cjs` and passes composition constraints to club-art and SVG rendering together, keeping generated subjects clear of overlaid names and optional stats.
- Graphics Studio selects a player's closest uploaded pose as its identity reference and retains generated player artwork in the private photo collection for later graphics.
- Player-only decade collections, including Y2K, 2010s and 2020s cards, use dedicated local SVG renderers with composition-selected frames and reuse an existing text-free artwork style, so fixed frame geometry and accurate lettering do not depend on AI-generated text.
- Card data is validated in `card-stats.cjs` against the exact club and EA baseline ID; missing metrics and unverified EA win records are omitted, while manual changes are labelled member-edited to prevent misleading claims.
- `card-layout.cjs` removes unused print-card stat bands and portrait artwork requests reserve only compact lettering space, so optional data never leaves empty panels.
- Signature cards (broadcast, heritage, esports, synthwave, mud) render in `graphics-signature.cjs` with style-specific text-free art from club-art, so each style's frame and lighting stay distinct.
- The 1974 Sicilia card (`graphics-sicilia.cjs`) posts a front and a back; the back's lore is seeded from the name and labelled fiction, while its stat line uses only validated card stats.
- Shirt numbers appear in art and on cards only when the vision check legibly read them from the player's own upload (`analysis.kit_number`); generated art never verifies a number, so numbers can't be invented.
- Recruiting posters use user-bound Graphics Studio drafts and a local lettering renderer with existing text-free poster art; uploaded club-logo collections are club-scoped and style-matched so another club never inherits Palermo branding.
- Uploaded club logos (even Automatic) override server branding and EA badges, are never cached or substituted on failure, and pass through `logo-cleanup.cjs` (backdrop knock-out, trim, die-cut outline) so crests blend into any background.
- All team-focused Studio artwork selects up to five distinct saved active players from the exact club roster and sends ordered identity references to club-art; group outputs are never stored as individual photo references, preventing cross-player identity contamination.
- Palermo kits live in `public/spotbot/club-kits.cjs`: vintage card styles auto-pair with a matching era kit and members can override per graphic from the draft prompt, so the art matches the card's era; non-Palermo clubs keep their saved `club.kit`.
- `fun-zone.cjs` roasts use real numbers; rumours are labelled fiction.
